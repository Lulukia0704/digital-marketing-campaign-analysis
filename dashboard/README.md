# Dashboard

Folder ini berisi dokumentasi visual dari **Digital Marketing Campaign Dashboard** yang dibuat menggunakan Google Looker Studio.

Dashboard ini menyajikan indikator performa kampanye digital marketing, efisiensi biaya iklan antar-kanal, tren performa berdasarkan hari, serta perbandingan anggaran dengan pengeluaran aktual.

File gambar dashboard digunakan sebagai pratinjau hasil visualisasi proyek.

**Tools:** Google Looker Studio.
