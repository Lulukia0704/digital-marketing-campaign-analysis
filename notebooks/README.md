# Notebooks

Folder ini berisi notebook Python yang digunakan dalam proses pengolahan dan persiapan data kampanye digital marketing.

Proses yang dilakukan mencakup pemeriksaan struktur data, pembersihan data, serta persiapan dataset agar siap digunakan untuk analisis dan visualisasi menggunakan Google Looker Studio.

**Tools:** Python, Pandas, dan Google Colab.
