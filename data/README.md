# Data

Folder ini berisi dokumentasi terkait dataset yang digunakan dalam proyek **Digital Marketing Campaign Performance & Budget Efficiency Analysis**.

Dataset digunakan untuk menganalisis performa kampanye iklan, interaksi audiens, efisiensi biaya pada berbagai kanal pemasaran, serta penggunaan anggaran kampanye.

Data yang digunakan merupakan data kampanye digital marketing. Dataset dipersiapkan sebelum digunakan dalam proses analisis dan visualisasi.

**Catatan:** Dataset mentah tidak disertakan dalam repository ini.
