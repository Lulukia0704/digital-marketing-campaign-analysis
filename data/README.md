# Data

Folder ini berisi dataset yang digunakan dalam proyek **Digital Marketing Campaign Performance & Budget Efficiency Analysis**.

Dataset digunakan untuk menganalisis performa kampanye iklan, interaksi audiens, efisiensi biaya pada berbagai kanal pemasaran, serta penggunaan anggaran kampanye.

Folder ini mencakup dua jenis dataset:

- `Marketing_campaign.csv`: Dataset mentah yang digunakan sebagai sumber data awal.
- `clean_marketing_data.csv`: Dataset hasil proses pembersihan dan persiapan data menggunakan Python dan Pandas.

Dataset hasil cleaning dipersiapkan agar memiliki struktur data yang lebih konsisten dan siap digunakan untuk proses analisis serta visualisasi menggunakan Google Looker Studio.

**Tools:** Python, Pandas, dan Google Colab.
